# Internal Operations Service Hub

The Internal Operations Service Hub is a product design for a platform that allows company employees to submit internal requests to departments such as IT, HR, and Finance and track their request status.

This repository contains the product specification, architecture, data model, and architecture decision record for the system.

## Current Scope

This repository focuses on the product foundation and system design.

It does not include:
- complete frontend or backend implementation
- production infrastructure
- CI/CD
- AI features
- unnecessary microservices or messaging systems
